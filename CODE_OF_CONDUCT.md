# Código de Conducta

## Compromiso

Este proyecto busca una comunidad abierta, técnica y respetuosa. Toda persona puede participar sin hostigamiento por identidad, experiencia, procedencia, capacidad, idioma, opinión técnica o forma de contribuir.

## Comportamiento esperado

- debatir ideas y evidencia, no descalificar personas;
- aceptar correcciones y explicar desacuerdos con claridad;
- respetar límites, privacidad y decisiones de moderación;
- dar crédito y declarar conflictos de interés;
- evitar presión para aprobar cambios sin revisión;
- ayudar a que la documentación sea accesible para distintos niveles de experiencia.

## Comportamiento inaceptable

- acoso, amenazas, insultos o discriminación;
- publicación de datos personales o comunicaciones privadas;
- contenido sexualizado o atención no deseada;
- suplantación, manipulación de evidencia o atribución falsa;
- divulgación pública de vulnerabilidades, secretos o incidentes sensibles;
- interrupción deliberada y repetida de la colaboración.

## Alcance

Este código aplica a issues, pull requests, revisiones, discusiones, activos, espacios oficiales del proyecto y representación pública de la comunidad.

## Reporte y limitación actual

El repositorio todavía no tiene un canal privado confirmado para reportes de conducta. No publiques nombres, capturas, mensajes privados ni detalles que puedan identificar a las personas involucradas.

Para solicitar coordinación **sin información sensible**, abre un [issue público mínimo](https://github.com/Blandskron/agents-first-repo-docs/issues/new) indicando únicamente que necesitas contactar al maintainer por un asunto de conducta. `@Blandskron` decidirá el siguiente paso disponible.

> [!IMPORTANT]
> Está pendiente que el owner publique un canal privado verificable. Hasta entonces, los reportes confidenciales no deben enviarse mediante GitHub Issues. Esta es una limitación de gobernanza conocida, no una garantía de confidencialidad.

## Aplicación

El maintainer evaluará el contexto y aplicará una respuesta proporcional, que puede incluir:

1. orientación o corrección privada cuando exista un canal seguro;
2. advertencia pública sin exponer información sensible;
3. restricción temporal de participación;
4. exclusión permanente de los espacios controlados por el proyecto.

Las decisiones deben registrar la justificación mínima necesaria, respetar privacidad y evitar represalias. Los conflictos del maintainer se manejan según [GOVERNANCE.md](GOVERNANCE.md).
