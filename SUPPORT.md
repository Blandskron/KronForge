# Soporte

Este repositorio es mantenido como proyecto open source y no ofrece un SLA de respuesta.

## Elegir la ruta correcta

| Necesidad | Ruta |
|---|---|
| Fallo reproducible en documentación, catálogo, portal o GitHub Pages | Formulario **Reporte de fallo** |
| Nuevo activo, mejora amplia o decisión estructural | Formulario **Propuesta de activo o RFC** |
| Pregunta general no sensible | Issue público breve, después de buscar respuestas existentes |
| Vulnerabilidad, secreto o dato personal | [SECURITY.md](SECURITY.md); nunca detalles públicos |
| Incidente de conducta | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |
| Contribución preparada | Pull request según [CONTRIBUTING.md](CONTRIBUTING.md) |

## Antes de pedir ayuda

1. Revisa [README.md](README.md), el [catálogo](library/README.md) y los issues existentes.
2. Incluye la URL o ruta afectada, resultado esperado, resultado observado y pasos reproducibles.
3. Indica navegador o entorno solo cuando sea relevante.
4. Elimina tokens, datos personales, contenido privado y capturas sensibles.

## Límites

- El proyecto no garantiza soporte para herramientas, modelos o proveedores externos.
- La compatibilidad de contenido no implica que un agente descubra archivos automáticamente.
- Las consultas profesionales externas al mantenimiento del repositorio no forman parte del soporte comunitario.
- Un issue puede cerrarse si es duplicado, no contiene evidencia suficiente o corresponde a seguridad o conducta sensible.
