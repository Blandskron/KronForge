# Roadmap del Framework

El roadmap prioriza profundidad, interoperabilidad y calidad sobre cantidad de archivos.

## v1 — Prompt y estándar agents-first

Prompt maestro, documentación operativa y primera experiencia web.

## v2.0 — Biblioteca por dominios

Catálogo, contratos, migración de prompts y activos reutilizables.

## v2.1 — Portal y pilares AI Engineering

- Context Engineering.
- Repository Engineering.
- MCP e integraciones.
- Hooks y workflows.
- Arquitectura de subagentes.
- Catálogo schema v2.
- Portal con búsqueda, filtros, dominios, breadcrumbs y visor de activos.

## v2.2 — Recorridos y profundidad

- modernización de sistemas legados;
- onboarding técnico;
- auditorías de arquitectura y seguridad;
- preparación de despliegues;
- RAG y evaluación de agentes;
- examples y case studies;
- troubleshooting MCP.

## v3 — Comunidad y automatización

- validadores automatizados;
- generación controlada de índices;
- plantillas de contribución;
- métricas de cobertura, uso y frescura;
- gobernanza por dominios.

## v4 — Ecosistema interoperable

- paquetes consumibles por agentes;
- integraciones opcionales;
- perfiles organizacionales;
- traducciones;
- múltiples versiones del portal.

Consulta la [estrategia integral](AI_ENGINEERING_FRAMEWORK_STRATEGY.md#24-roadmap) para decisiones, riesgos y criterios de cada fase.
