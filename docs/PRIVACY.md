# Privacidad en KronForge

**Revisado el** 2026-11-27.

Esta página describe los flujos identificados en el portal estático y en sus canales de colaboración. El [código y los activos](https://github.com/Blandskron/KronForge) se publican en GitHub.

## Al usar el portal

- GitHub Pages sirve el sitio y registra la dirección IP de quienes lo visitan para fines de seguridad. Sus propios controles y condiciones aplican a esos registros. [Recolección de datos en GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection).
- El navegador conserva el tema seleccionado en su almacenamiento local. Puedes borrar esa preferencia limpiando los datos de este sitio en el navegador.
- La búsqueda de la biblioteca se ejecuta en el navegador. El texto y los filtros pueden aparecer en el enlace que copies y en tu historial. Usa términos de búsqueda que puedas compartir.
- El portal permite copiar y descargar Markdown por acción del visitante. Si decides entregar ese contenido a un agente, los archivos que compartas y su tratamiento dependen del proyecto y del servicio que uses.

## Al participar en GitHub

Los issues y las pull requests de este repositorio son públicos. Para un fallo, comparte pasos reproducibles y evidencia saneada. Si necesitas coordinar una consulta de privacidad, puedes abrir un issue con una solicitud breve de coordinación y reservar los detalles para un canal acordado. Para una exposición de datos o una vulnerabilidad, usa la ruta de seguridad. [Soporte](../SUPPORT.md) · [Reportes de seguridad](../SECURITY.md) · [Declaración de privacidad de GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
