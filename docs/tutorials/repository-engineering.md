# Dar a humanos y agentes un punto de entrada

**Nivel** · Inicial

**Prerrequisito** · Elegir un árbol local de solo lectura y disponer de Git si se usa el ejemplo histórico.

Consulta [Diseño de un repositorio AI-First](../../library/domains/repository-engineering/playbooks/design-ai-first-repository.playbook.md) antes de empezar.

## Ejercicio

1. Dibuja un mapa de tres entradas. Usa `README.md` para explicar el producto, `AGENTS.md` para la operación y un runbook para un flujo recurrente.
2. Desde el contrato operativo, sigue la ruta a un control real y coteja el comando con el manifiesto. Marca reglas duplicadas y el documento dueño de cada una.
3. Entrega el mapa a otro lector con el encargo de elegir cómo validar una edición documental y cuándo necesita aprobación.

## Entrega y aceptación

Un mapa de responsables, archivos y comandos con citas de origen. El lector llega al comando verificable y al límite de permisos siguiendo la documentación.
