# Auditar una instrucción antes de publicarla

**Nivel** · Inicial

**Prerrequisito** · Elegir un documento con enlaces y al menos un comando.

Consulta [Comandos inventados](../../library/domains/documentation-knowledge/anti-patterns/invented-commands.anti-pattern.md) antes de empezar.

## Ejercicio

1. Encuentra en una guía el comando `npm run validate` y contrástalo con `package.json`. Sigue un enlace interno hasta la fuente que respalda la instrucción.
2. En una nota local, redacta una instrucción de ejemplo con un comando sin respaldo y marca la comprobación como pendiente. Conserva el documento canónico intacto.
3. Registra documento, texto, evidencia y decisión editorial. Ejecuta la validación para complementar la revisión de enlaces y metadatos.

## Entrega y aceptación

Un informe breve con instrucciones confirmadas y pendientes justificados. Cada comando confirmado se encuentra en una fuente ejecutable y cada pendiente explica qué evidencia falta.
