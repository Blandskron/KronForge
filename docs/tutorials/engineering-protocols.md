# Cerrar una tarea con evidencia y nivel de revisión

**Nivel** · Intermedio

**Prerrequisito** · Tener una tarea concreta, un criterio de aceptación y un control ejecutable.

Consulta [Evidencia y compuertas de calidad](../../library/domains/engineering-protocols/protocols/evidence-and-gates.protocol.md) antes de empezar.

## Ejercicio

1. Usa como tarea una corrección documental. Identifica el estado del código, el criterio y el comando que lo comprueba.
2. Completa un registro con resultado y observación. Declara como autorrevisión cualquier verificación hecha por la misma persona y conserva como pendiente una compuerta que no pudiste ejecutar.
3. Prepara el recibo e incluye el próximo paso si falta una decisión. Usa el caso histórico para distinguir una observación del repositorio de evidencia independiente.

## Entrega y aceptación

Un recibo con estado, evidencia vigente, nivel de revisión y asunto por resolver. El cierre se puede reconstruir a partir del comando, el resultado y el estado del repositorio.
