# Delimitar una medición de carga del portal

**Nivel** · Intermedio

**Prerrequisito** · Tener un flujo repetible y conocer qué recurso se quiere estudiar.

Consulta [Validación básica de performance](../../library/domains/reliability-performance/prompts/performance-basic-validation.prompt.md) antes de empezar.

## Ejercicio

1. Elige abrir el portal o el visor de un activo. Enumera qué solicitudes visibles participan y dónde termina el flujo elegido.
2. Formula una pregunta medible, por ejemplo si servir una guía añade una solicitud al abrir el visor. Fija navegador, ruta, condición de caché y observación antes de comparar.
3. Registra el método y un posible factor de confusión. Usa la verificación de rutas como prerrequisito para medir y conserva aparte las muestras si ejecutas una medición.

## Entrega y aceptación

Un plan de medición con condición de comparación, indicador y límite. El plan permite repetir la misma observación y evita inferir rendimiento de un resultado HTTP correcto.
