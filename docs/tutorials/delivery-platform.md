# Verificar un portal bajo su ruta de publicación

**Nivel** · Intermedio

**Prerrequisito** · Tener Node.js y conocer el prefijo publicado de KronForge.

Consulta [Publicación en GitHub Pages](../../library/domains/delivery-platform/skills/github-pages-release/SKILL.md) antes de empezar.

## Ejercicio

1. Identifica la página raíz, un recurso de interfaz y un Markdown canónico. Explica cómo el prefijo `/KronForge/` afecta a cada URL.
2. Ejecuta `npm run smoke` y registra el recuento de rutas, la comprobación del tipo de contenido y el tratamiento de rutas inexistentes.
3. Lee el caso del workflow para separar evidencia local, calidad de integración y decisión de publicación. Conserva la URL de la ejecución que respalda el resultado.

## Entrega y aceptación

Un registro con tres URLs esperadas y las evidencias locales y de CI disponibles. El registro cita las rutas bajo el prefijo y distingue qué comprobó cada entorno.
