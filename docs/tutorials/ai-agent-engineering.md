# Delegar una revisión de documentación

**Nivel** · Inicial

**Prerrequisito** · Leer el patrón de delegación y elegir un archivo Markdown con una instrucción ambigua.

Consulta [Delegación por contrato](../../library/domains/ai-agent-engineering/patterns/subagent-contract.pattern.md) antes de empezar.

## Ejercicio

1. Delimita la tarea a revisar una instrucción en `README.md`. Incluye la regla que debe conservarse, la ruta editable y un ejemplo del resultado esperado.
2. Rellena el contrato. Pide al revisor que devuelva hallazgo, evidencia y propuesta, con autorización de lectura únicamente durante la revisión.
3. Añade una petición de ejemplo fuera del alcance, como cambiar la configuración de publicación. Registra si el revisor la escala y entrega solo el resultado acordado.

## Entrega y aceptación

Un contrato y un recibo con ruta, criterio verificado y asuntos escalados. La evidencia apunta a la instrucción original y se puede distinguir la revisión de una edición autorizada.
