# Revisar una skill antes de adoptarla

**Nivel** · Intermedio

**Prerrequisito** · Tener a mano el Markdown canónico y su versión distribuida.

Consulta [Privilegio mínimo en herramientas de skill](../../library/domains/agent-supply-chain/patterns/least-privilege-skill-tools.pattern.md) antes de empezar.

## Ejercicio

1. Lee la skill de auditoría documental sin ejecutarla. Ubica procedencia, pasos y herramientas declaradas.
2. Cruza cada paso con una capacidad. Distingue acceso de lectura de una escritura y registra qué decide el host sobre los permisos.
3. Comprueba la proyección con el caso enlazado. Documenta qué evidencia pedirías si el origen o los permisos de una versión futura cambiaran.

## Entrega y aceptación

Una tabla de paso, capacidad requerida y permiso propuesto, más una decisión de adopción. Cada permiso tiene un paso que lo justifica y la decisión cita una versión reproducible.
