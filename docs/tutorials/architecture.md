# Decidir cómo publicar una proyección de documentación

**Nivel** · Intermedio

**Prerrequisito** · Poder identificar una fuente canónica y un consumidor del catálogo.

Consulta [Plantilla de decisión arquitectónica](../../library/domains/architecture/templates/adr.template.md) antes de empezar.

## Ejercicio

1. Lee la decisión del catálogo en el caso enlazado. Identifica quién mantiene el Markdown y qué lee el portal.
2. Compara extender el catálogo y publicar una fuente complementaria para la guía. Evalúa compatibilidad, recuperación y mantenimiento de cada opción.
3. Completa una decisión con el riesgo de indisponibilidad y la comprobación que motivaría reconsiderarla.

## Entrega y aceptación

Una decisión con alternativas, efectos sobre consumidores y una señal de reevaluación. La decisión cita la fuente y el consumidor y expone cómo observar una regresión.
