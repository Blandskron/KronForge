# Elegir la frontera de una delegación

**Nivel** · Intermedio

**Prerrequisito** · Preparar tres necesidades concretas de un agente que trabaja con documentación.

Consulta [Fronteras entre protocolos de agente](../../library/domains/agent-interoperability/references/protocol-boundaries.references.md) antes de empezar.

## Ejercicio

1. Clasifica leer convenciones locales, consultar información remota y delegar un entregable. Anota qué relación de autoridad requiere cada una.
2. Dibuja una delegación de revisión a un par. Enumera el resultado esperado, el contexto mínimo y quién valida su identidad y la respuesta.
3. Evalúa un caso donde falte confirmación de identidad. Registra qué operación queda pendiente y qué información puede seguir procesándose localmente.

## Entrega y aceptación

Una matriz de necesidad, mecanismo, autoridad y comportamiento al faltar confianza. El diseño identifica la decisión humana y distingue la clasificación de una prueba de integración.
