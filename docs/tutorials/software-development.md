# Comprobar compatibilidad antes de cambiar una interfaz

**Nivel** · Intermedio

**Prerrequisito** · Elegir un consumidor y una propiedad pública que utilice.

Consulta [Compatibilidad de consumidores](../../library/domains/software-development/checklists/consumer-compatibility.checklist.md) antes de empezar.

## Ejercicio

1. Usa el catálogo v3 como ejemplo. Identifica un campo consumido por el portal y registra su tipo, ruta y valor válido.
2. Esboza un cambio editorial compatible y otro hipotético que altere el tipo. Mantén ambos como propuestas y explica qué chequeo debe distinguirlos.
3. Ejecuta la validación del caso y registra lo que demuestra el resultado para el consumidor elegido.

## Entrega y aceptación

Una matriz con interfaz, consumidor, cambio propuesto y comprobación. El cambio de tipo tiene un fallo esperado y el cambio editorial conserva el contrato observable.
