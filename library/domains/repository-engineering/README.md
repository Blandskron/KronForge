# Repository Engineering

Diseño y mantenimiento de repositorios preparados para colaboración prolongada entre personas y agentes.

## Capacidades

- entradas diferenciadas para humanos y agentes;
- instrucciones por alcance;
- módulos, ownership y límites;
- comandos verificables;
- contexto progresivo;
- skills y activos reutilizables;
- navegación, versionado y obsolescencia;
- validación documental automatizable.
