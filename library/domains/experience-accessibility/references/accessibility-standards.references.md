# Referencias: Estándares de Accesibilidad Web

Última revisión: 2026-07-28.

## Fuentes

- [Web Content Accessibility Guidelines (WCAG) 2.2](https://www.w3.org/TR/WCAG22/): criterios de conformidad para contenido web. Úsala como fuente normativa; no sustituyas sus criterios por un resumen.
- [WAI-ARIA 1.2](https://www.w3.org/TR/wai-aria-1.2/): semántica para componentes y estados que HTML nativo no expresa por sí solo.
- [ARIA Authoring Practices Guide](https://www.w3.org/WAI/ARIA/apg/): patrones de interacción y teclado para widgets. Es guía práctica, no criterio de conformidad.
- [HTML Accessibility API Mappings](https://www.w3.org/TR/html-aam-1.0/): relación entre elementos HTML y APIs de accesibilidad.

## Uso responsable

Prioriza HTML semántico antes de ARIA, prueba con teclado y tecnologías de asistencia, y combina herramientas automáticas con evaluación humana. No declares conformidad solo porque un escáner no encontró errores.
